# Registro Ambiental

Protótipo acadêmico simples de uma página web para registrar problemas ambientais encontrados em um bairro.

## Recursos
- Cadastrar o tipo de problema, o local de referência e a descrição.
- Consultar e excluir registros.
- Guardar os dados no navegador com `localStorage`.

## Tecnologias
HTML, CSS, JavaScript e Bootstrap 5.3.

## Como usar
Abra `index.html` em um navegador. É necessário acesso à internet para carregar o estilo do Bootstrap pela CDN. Se desejar publicar, envie os arquivos para um repositório do GitHub e habilite o GitHub Pages.

## Limitações
Os dados permanecem apenas no navegador utilizado. O sistema não envia ocorrências a órgãos públicos, não possui login ou banco de dados remoto e ainda não foi validado com moradores reais.
